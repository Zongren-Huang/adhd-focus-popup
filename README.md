# ADHD Focus Popup

A Windows desktop app that keeps a single prioritized task visible in an always-on-top sticky note, and nags you with a custom voice recording when you've gone idle.

## ⬇️ Download Here

**[Download for Windows](https://github.com/Zongren-Huang/adhd-focus-popup/releases/latest)**

Run the installer — it installs with a single click (no admin permissions needed) and launches automatically.

> Windows may show a "Windows protected your PC" screen the first time you run it, since this isn't a code-signed installer. Click **More info**, then **Run anyway**. This is expected for a small independently-built app.

## What it does

- Keeps your Current Task always visible in a small, always-on-top sticky note
- Detects when you've gone idle and plays a Reminder in a voice you recorded yourself
- Supports multiple Voice Profiles, each with its own Nag Clip and optional Done/Snooze Acknowledgment Clips
- Resets daily, carrying unfinished tasks over to the new day
